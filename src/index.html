02 / 论证分析筹备中

Lumraketo 照明弹

围绕公共议题，区分原文与重构，检查前提、证据和推理，并呈现无法由逻辑单独解决的价值分歧。

03 / 认知研究筹备中

Kognarkeo 认知方舟

从明确的问题和概念出发，探索认知、思维与群体行为；根据可获得的材料选择研究方法。

关注：研究问题 / 方法选择 / 证据边界

04 / 学习笔记筹备中

Lernomodulo 学习模块

以问题组织学习，将来源、核心概念、推理和自己的理解写清楚，也留下尚待理解和核验的部分。

关注：来源 / 解释 / 反例与待核验项
